	\section{Seismic Amplitude Research at Whakaari/White Island}
	
	Using seismic amplitude data from the WIZ and WSRZ stations, I built a
	reproducible R workflow covering data retrieval from the university
	server, preprocessing, feature computation and visualisation.
	
	\begin{itemize}
		\item Computed weekly ordinal-pattern features (7-day windows with 1-day
		overlap and 6-day overlap) from 10-minute RSAM data for July
		2014 -- December 2019, for the entropy and complexity measures.
		\item Applied $k$-means and DBSCAN clustering and a class-weighted RBF
		support vector machine, and validated the results against the
		GeoNet Volcanic Alert Level (VAL) record using PCA and Sankey
		visualizations.
		\item Found that clustering alone did not reliably isolate eruptive
		periods, such as the 9~December 2019 eruption, even though these
		periods are clearly visible in the $H\times C$ plane and feature
		time series. This led me to develop a threshold-based anomaly
		detection approach and an event coincidence analysis (ECA) that
		tests whether feature-anomaly weeks coincide with eruption weeks,
		a novel application of ordinal-pattern features.
		\item Drafted a report, ``Ordinal-Pattern Cluster Analysis of RSAM Time
		Series for Detecting Volcanic Seismic Anomalies at Whakaari,
		2014--2019'', and shared the results with a volcanologist
		collaborator for expert review of the ground-truth labels.
	\end{itemize}
	
	\section{Thesis Development}
	
	I have largely completed the literature review, which surveys how
	ordinal-pattern features are used across scientific domains and
	identifies a clear gap: these features have rarely been used for time
	series clustering or event coincidence analysis. I have also produced
	simulation results in which 13 ordinal-pattern features computed from
	convex-combination time series are clustered using the $H\times C$ plane,
	$k$-means and DBSCAN. I am currently writing the methodology chapter for
	completed work.
